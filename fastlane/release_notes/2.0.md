Scanny 2.0 is a rewrite of the app in Kotlin Multiplatform and Compose Multiplatform. One codebase for Android and, coming next, iOS.

## Scan

- Scans with the camera, one code or several at once, or from an image of the gallery.
- Supported formats: QR Code, Data Matrix, Aztec, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 39, Code 93, Code 128, ITF and Codabar.
- Every content read and shown field by field, with its action:
  - links and deep links of apps;
  - e-mail, SMS, MMS, phone call;
  - Wi-Fi networks, WPA3 and enterprise ones included;
  - contacts (vCard and MeCard) and calendar events;
  - places on the map;
  - one-time passwords, added to an authenticator;
  - bitcoin payments.
- History of the scans, groups of a multiple scan included, kept as long as chosen.

## Create

- QR codes, Data Matrix, Aztec codes, PDF417 and barcodes, with every field of each format, required fields marked.
- QR codes customized: colors, gradient, shapes of the dots and corners, logo, error correction, with a readability warning.
- A scanned or created code edited into a new one; created codes shared or saved as images.

## Under the hood

- Corrected Data Matrix and Aztec encoders, checked against ZXing.
- Baseline profiles for a faster start.
- A splash screen.
- CI on every pull request, and publishing in one click.

Scanny는 QR 코드와 바코드를 스캔하고 만듭니다. 가볍고 빠르며, 광고도 계정도 없습니다.

<b>스캔</b>
• 카메라로 코드 하나 또는 여러 개를 한 번에, 또는 갤러리의 이미지에서 스캔
• 13가지 형식: QR Code, Data Matrix, Aztec, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 39, Code 93, Code 128, ITF, Codabar

<b>이해하고 바로 실행</b>
Scanny는 코드에 담긴 내용을 항목별로 읽고, 알맞은 동작을 제안합니다.
• 링크 열기
• Wi-Fi 네트워크 연결
• 연락처 추가, 캘린더에 일정 추가
• 이메일이나 SMS 쓰기, 전화 걸기
• 지도에서 장소 보기
• 인증 앱에 일회용 비밀번호 추가
• 비트코인 지갑 열기

<b>만들기</b>
• QR 코드, Data Matrix, Aztec 코드, PDF417, 바코드 만들기, 내용마다 모든 항목 지원
• 입력하는 대로 코드가 그려집니다
• 나만의 QR 코드: 색상, 그라데이션, 점과 모서리 모양, 로고, 오류 정정
• 코드를 공유하거나 이미지로 저장

<b>기록</b>
• 스캔한 코드와 만든 코드를 원하는 기간 동안 보관
• 모든 코드를 다시 그려, 바로 공유하거나 저장 가능

<b>개인정보 보호</b>
광고도 계정도 없습니다. 코드는 휴대전화에만 남습니다.
